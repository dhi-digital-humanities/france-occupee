fs-bench

Stemming via multilingual-stemmer@2.1.1 (WASM) and fuzzy search via fuse.js@7.1.0, both from unpkg. Corpora are built from data/services.json + data/sources.json by node test/benchmark/build-fs-bench.mjs; place strings are excluded. Everything runs on the main thread on purpose, so the absolute numbers include whatever UI blocking they cause.
